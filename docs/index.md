# 九阶段成果索引

本次选题：招聘需求澄清与面试协同。九阶段包含27项子任务，完整机器可读结论见 [task-records.json](task-records.json)。

1. [业务挖掘](01-opportunity.md)：机会、合成基线、章程与决策链。
2. [现场调研](02-discovery.md)：六角色访谈、无AI判断流程、四来源核对与证据。
3. [需求定义](03-definition.md)：优先级、需求边界、验收标准。
4. [方案设计](04-solution.md)：人工/规则/模型比较、权限与架构、情景报价及ROI。
5. [构建集成](05-build.md)：契约、可运行闭环、六类异常与审计。
6. [测试评估](06-validation.md)：评估集、三轮执行、缺陷修复和剩余风险。
7. [客户试点](07-pilot.md)：受控试点、虚拟角色问题、真实UAT与价值核验待执行。
8. [上线交接](08-handoff.md)：三方虚拟评审、本地恢复、运行手册，正式上线NO-GO。
9. [运营迭代](09-operation.md)：30/60/90天节奏、旧版条件事件演练、下一轮发现。
