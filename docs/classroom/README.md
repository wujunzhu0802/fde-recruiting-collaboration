## 本次测算口径

全部为教学预算或沿用课程输入，**不是已发生费用、厂商实时价或已获客户批准的正式报价**。实际客户人数与日均业务量仍未核实。API路线需客户授权、脱敏与安全评审；不获批准时须另评内网或私有化，不得直接套用本预算。

人天综合成本＝22000×1.55÷21.75÷80%＝约1959.770115元。对外参考单价＝内部成本×1.25＝约2449.712644元；25%成本加成对应20%毛利，不是25%毛利。金额由未取整的单价计算，单价与金额的显示精度不同可能产生末位显示差异。

一次性人力工作量20人天，缓冲4人天，归入“人力”成本；数据清洗与复核2.5人天，缓冲0.5人天，归入“数据”成本。实施合计27人天。数据工作量不重复计入人力块。全年响应巡检6人天、版本维护4人天另计运维，不重复归入一次性实施人天。所有任务是重新交付该范围的估算，不是本次开发的实际工时。

模型预算按每月2000次、每次输入2400/输出500 Token、1步、不重试，输入/输出自定义预算单价10/30元每百万Token计算。输入年成本576元、输出年成本360元，合计936元。**单价是未选定供应商前的教学预算输入，Token量未实测**。既有MVP验证仅执行原文摘录及模型测试替身，不能把936元当成已经支付的API账单。

服务器按CPU服务120元/月、备份存储80元/月，共2400元/年估算。运维范围限定为10人天/年，不含无限调优、新接口、GPU、高可用或私有化。

## 练1报价公式验算

五块首年内部预算成本合计约75847.49元。其中一次性实施成本约52913.79元，年度持续成本约22933.70元。分别加10%风险预留与25%成本加成，再按百元向上取整：实施费72800元、年服务费31600元，首年合计104400元，续年31600元。超量模型调用参考单价0.06元/次，只在相同Token上限的预算条件下成立；当前系统没有自动计费功能。

选择“订阅制”，拟采用实施费加年服务费及超量单价的组合。工时缓冲覆盖任务估算，报价风险预留覆盖剩余报价不确定性，各只计算一次；成本表使用内部成本单价，不用已加成的人天售价再次加成。

这里只是练1要求的报价验算，并非练6正式合同报价；尚未完成真实Token分词、供应商签约价、正式SLA或客户ROI复核。历史 [8000元简化原型情景](../roi.md)的范围与本次重新交付预算不同，保留作历史记录，不能混用其ROI结论。
